# 上传飞书招聘

本模块自带执行器，可单独复制安装。接收已核验的简历文件、候选人身份依据、来源、可选岗位及任务授权；不要求来自某个招聘渠道。

首次启用上传、配置缺失或连接变化时，先运行 `scripts/hire-upload.mjs onboard --config <本地配置路径>`，按[接入配置](references/setup.md)主动引导用户完成应用选择、权限开通和映射。将返回的当前步骤、所需权限和操作入口说明给用户，完成一步后继续下一步，不能只发文档链接。已配置且连接已核验时直接使用[上传命令](references/commands.md)；不重复引导创建应用。仅使用 BOSS 功能时不触发飞书配置。

使用 `scripts/hire-upload.mjs` 完成归档、精准查重、固定计划、执行和回读。路径相对于本 Skill；候选人字段从 stdin 输入，配置只保存连接名称、来源与岗位映射，不保存凭证。应用与文件权限由使用者自己的环境提供。

- 执行范围来自用户已确认的任务或已记录的有效持续授权。准备出的计划已被覆盖时直接执行，无需逐份重新征求授权；新用户不继承任何原作者的授权。
- 已有人才复用，已有同岗位投递只补新附件。人才入库与关联岗位分别验收；仅人才入库须是任务明确选择。
- prepare 保存查重后的决策；execute 使用原计划引用和同一候选人输入。未知写入先 reconcile，只读核验，不重放。
- 成功须核验人才下的正式附件；目标包含岗位时还须核验对应投递。入库不代表评审通过，不推进阶段，不发消息或安排面试。

配置、权限、身份或未知写入问题按[失败索引](references/failures.md)处理；接口与权限依据见[接口契约](references/api.md)。结果返回文件哈希、人才/附件/投递引用、状态及剩余步骤，由调用 workflow 保存原任务断点。
