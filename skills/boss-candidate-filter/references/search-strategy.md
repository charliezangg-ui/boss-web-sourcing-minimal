# 先窄后宽与页面切换

每岗可建立 N1 核心职责、N2 相邻职责、W1 去除过窄词三个召回版本。版本的学历、院校、薪资、经验、城市、活跃度及去重值全部来自本轮用户要求和实际页面；本包不预设任何学校或薪资门槛。专业只在岗位确有要求时设置。关键词是召回假设，不能变成评审硬条件。推荐、最新与搜索的控件和保存方式分别核对。

低产出固定顺序：①推荐页当前已核验条件，下降时切最新且原样复用；②最新再下降，切推荐，仅放宽过窄关键词或换相邻责任词；③关键词放宽后的推荐再下降，切最新且复用；④最新再下降，切推荐，放宽用户允许放宽的学校要求；⑤重复“推荐→最新同条件→推荐下一项已授权召回扩宽”。院校若由指定学校改为不限，只有学校层放开；用户确认的学历底线继续保持。活跃度影响回复效率，未经用户明确授权不放宽；经验、薪资、城市及核心画像也不擅自放宽。无可放宽项时换已授权语义假设、核对可用入口与重复率；可证明池耗尽才记阻塞，不因低通过率结束目标。

每轮开始在[策略账本](../../boss-candidate-source/references/strategy-ledger.md)预设窗口人数与下降判据，记录基准与当前分子分母、读失败和重复数。没有已验证的固定数值阈值；小样本写 insufficient_sample，不能事后调阈值。通过率只触发策略变化，不触发任务终止。页面切换、刷新、完整 reload 均可能清空条件；每次重读岗位和完整 effective 值。不无限下刷同一低产出页，不靠反复切页试探平台风控。刷新频率与深度没有通用安全值，若用户设试验预算须与平台安全阈值分开。

搜索与精选可能消耗畅聊卡；浏览及筛选与付费开聊分开。购买、预算、扣点和余额按当前页面及用户授权执行，不沿用原账号历史额度。每策略版本分别记录卡片、详情、评审、可联系、重复、耗时和切换次数；回复率是后续 cohort 指标，不混作筛选通过率。
