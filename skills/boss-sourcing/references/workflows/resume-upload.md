# 简历上传

Workflow ID：`resume_upload`。

输入为已核验简历文件、候选人身份依据、来源、岗位或仅人才入库目标，以及任务授权。来自 BOSS 的附件先复用[收简历模块](../../../boss-resume-collect/SKILL.md)的结果；已取得的本地文件直接交接。

将文件与目标交给[飞书招聘上传模块](../../../feishu-hire-upload/SKILL.md)，由其处理首次配置、归档查重、固定计划、上传和回读。已有入库回执直接复用，只续接未完成步骤。

接收成功、待核验、未知或阻塞结果与系统引用，写回原任务。具体授权和成功规则由上传模块维护。
