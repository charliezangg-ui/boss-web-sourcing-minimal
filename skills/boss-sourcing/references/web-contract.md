# BOSS 网页操作与模块契约

## 浏览器与授权

仅使用招聘端网页及当前浏览器工具支持的能力；先读工具说明。一个运行保持同一账号、浏览器空间和 run_id；多岗位任务逐岗绑定，每次动作核验当前对象所属岗位。页面动作以当前 DOM/截图定位，写入串行；页面变化后重新核对元素和身份。读取目标区域，避免反复输出整页快照。不使用旧 App 坐标、隐藏接口、过期选择器或绕过登录与平台安全验证。

创建岗位、联系候选人、收藏、请求简历及下载分别按用户授权范围执行。已授权数量内无需逐人重新授权；付费权益、购买、替换或关闭岗位、扩大目标或收件范围另行确认。付费弹窗只阻塞相关动作；核对已保存的岗位并继续其他独立授权动作。搜索/精选开聊可能消耗权益：先读实际扣点和余额，未知或超出预算则不提交，不点击可能直接发送的按钮探测费用。

## 运行状态与控制权

私有运行目录由用户提供，或在工作区 `.runtime/boss-web/<run_id>/` 建立，不得提交。记录 run_id、岗位/JD与规则版本、原始目标、授权动作、浏览器对象、当前策略、状态、下一动作及证据。运行状态 `ready/running/paused/completed/stopped` 与模块结果 `verified/blocked/unknown/skipped` 分开。外部写入前持久化 intent 并确认成功，失败则停止依赖写入；动作后回读同一对象；未知先只读核验，不重放。每人完成后即时落盘，落盘失败则暂停新增外部写入。

浏览器控制权只由一个任务持有。另一任务或用户接管时保存断点并交还；租约过期也先核实原持有者和页面。登录、安全验证、账号身份歧义停止 BOSS 动作；明确恢复后核对原空间、岗位、筛选和待核验写入。完成后按浏览器工具规则释放空间；阻塞时保留断点。

## 失败与数量目标

任一步失败先停其依赖链，按[失败恢复](../../boss-failure-recovery/SKILL.md)保存事件；安全验证按[安全反馈](../../boss-security-feedback/SKILL.md)。打开详情失败不得继续截图，截图失败不得继续 OCR；消息结果未知不得再次发送。

人工指定 N 个合格招呼时，只有同人同岗资格与发送回读均验证的唯一人数达到 N 才完成。通过率下降、切页、跨日、工具超时或一次模型回合结束都不是终点；按[策略](../../boss-candidate-filter/references/search-strategy.md)调整召回，保持原目标和规则。仅用户明确停止/截止、真实控制或安全阻塞、可证明的池耗尽或技术资源阻塞可暂停；报告原目标、剩余量、断点及恢复条件。没有已配置并核验的独立执行器，不能宣称会自动续接。
