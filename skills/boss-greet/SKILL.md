# 打招呼

输入当前 `contact_now` 判定、岗位卡/排除版本、同人同岗详情证据及用户授权的数量和内容。先核对排除、职业主线、持续责任、本人项目行动各关；只有通过标签或关键词摘要不构成证据。旧规则下结论、缺关或版本过期先返回评审。命中已确认排除直接跳过，不为凑数量放宽门槛。

核对当前候选人、岗位、历史会话及本运行记录。优先使用已核验的岗位特定招呼语；旧岗无特定配置时读取账户现有通用预设。BOSS按钮可能即时发送，文本不准确或涉及未授权披露则先解决内容，不能先点后看。不额外追加公司内部信息或求简历。搜索/精选如消耗权益，先核对实际扣点、余额及预算授权。

保存 send intent，单次点击，回读同人会话新增消息或平台明确发送状态；按钮颜色或跳转不足以证明送达。仅本轮当前标准下合格、同人同岗回读成功的唯一候选人计入目标。超时/unknown 先查原会话，不重发；历史误发和历史旧标准消息单列质量记录，不自动补量。
