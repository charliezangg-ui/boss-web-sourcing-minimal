# 单人快速闭环与效率验证

同岗每轮只建立一次岗位卡；换岗、JD或用户规则变化时重建，不能继承上一岗隐性门槛。读目标岗位未读列表并保存匿名键、入站指纹；上一人未 terminal 不开始下一人。用当前 DOM 取得选择器，若可用读取适配器，可合并打开、等待同人同岗、读取聊天及必要简历；适配器不能靠关键词自行拒绝。

冻结一级原始结论，明确排除/不匹配可只记已读；缺证才开完整详情。短简历直接读，长简历用渲染画布或重叠截图，折叠内容单独展开，与全文核验；身份和页底不省略。评审按排除→职业主线→持续责任→本人项目。外发 intent、同人回读，结果 unknown 时停。单人终态、证据与阶段耗时即时落盘后再看下一人。

对照实验如获用户授权，应固定同岗同规则并预先分组，分开编译、开发、生产读取、恢复时间；比较总时长、往返、详情次数、失败和判断一致性。不同简历复杂度带来混杂，同模型复核不是独立人工标签。未覆盖的真实分支记未测试，不为实验重发或触发安全控制。会话切换应避免高频连续跳转；具体间隔是可观测运行参数，不宣称平台安全阈值。发生验证立即停止并保留同 run 断点。
