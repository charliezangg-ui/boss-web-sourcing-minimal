# 完整简历读取：原视口、画布与折叠补图

复用已授权浏览器空间及同人详情。可读 DOM 优先直接提取；短简历在原视口完整时直接读；长简历用当前渲染画布导出，若导出受跨域限制则用有重叠的可见截图覆盖全文；折叠内容在原视口展开单独留图。临时调整视口后 finally 恢复，视口变化可能重置折叠状态，主图与补图共同核验。不可通过隐藏状态、接口或绕过验证取内容。

OCR按位置保留文字行；macOS Vision 适配器可按约2000像素高、100像素重叠分块识别中英文，合并位置、去重和排序。右侧日期与左侧经历要按版面核对，不按纯文本顺序乱接。检查姓名/同人、工作起止、项目、教育、技能和页底；原简历本来无某章节不当漏读。OCR含糊的公司、日期、个人责任与排除证据回看局部原图。保存 capture_complete、ocr_complete、critical_fields_verified 与缺口；任何折叠补图缺失或页底未覆盖都不能标完整。

前置链详情打开→绘制就绪→截图/导出→OCR→覆盖核验→评审，失败即停下游。旧文件不得用于下一候选人。画布未重绘、正文过长、OCR不可用时才回退分段截图；确认滚动位置变化后再截，不重复同一画面。截图成功不等于全文覆盖。读不到标 blocked_read，不转换为候选人能力不足。可选 Ego Lite/macOS 脚本见[读取模块](../../boss-candidate-read/SKILL.md)，运行前检查环境依赖。
