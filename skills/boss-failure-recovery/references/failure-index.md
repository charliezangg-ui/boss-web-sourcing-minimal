# 典型失败索引

按症状路由，操作前须有当前页面证据；条目本身不是重试授权。每次实例写私有日志，同类型归并；本索引只保留可复用机制，不含候选人或原账号证据。`verified` 只说明所记实例中成功，不能推断所有页面稳定。

| ID / 症状 | 最小恢复 | 完成条件与停止边界 |
|---|---|---|
| F01 点击超时、固定栏遮挡 | 看目标矩形与遮挡；在真实滚动区移到可见中部，再按当前DOM导航一次 | 同人详情就绪；仍失败 blocked_read，不用JS穿透 |
| F02 普通弹窗遮挡 | 分类付费、权限、加载或验证；普通可关闭浮层只点明确关闭控件 | 目标可操作；身份或控制权不清则停 |
| F03 点击后仍加载/Canvas missing | 先查详情确已打开、同人身份与正文绘制，再有界等待 | 详情就绪才截图；超时不OCR、不评审 |
| F04 Stale ref | 重读目标区域、核对岗位/对象，重建引用 | 只对无写入的导航有界重试，写入先核验 |
| F05 连续相同截图 | 核对实际滚动容器与位置，优先全文画布或带重叠截图 | 无新内容停止截图循环 |
| F06 上游失败后仍执行下游 | 停依赖链，丢弃未核验旧产物，修正失败传播 | 每步成功且同人才能进入下一步 |
| F07 发送/提交结果未知 | 留原intent，查原会话/岗位状态 | 成功才计数；unknown不重发/重提交 |
| F08 登录或安全验证 | 按安全反馈暂停、记录、交还 | 人工完成并明确继续后原空间核验 |
| F09 用户接管或空间失活 | 保存租约与断点，按浏览器工具交还 | 控制权恢复、原对象重核；不抢占 |
| F10 付费名额窗口 | 关闭付费窗口，查已保存与在招状态 | 不自动购买/替换旧岗位 |
| F11 本地相对路径 ENOENT | 核对执行 cwd，使用绝对私有运行路径；复用已创建空间 | 成功读写；不能因日志失败新建空间 |
| F12 下载事件超时 | 留intent，查原页、预览和本地文件 | 同附件完整文件/哈希才成功；unknown不重复下载 |
| F13 长简历裁切/空图 | 核对可见iframe、父容器高度、Canvas绘制和页底；可见图非空才OCR | 未覆盖全文 blocked_read；重复同类失败停流程 |
| F14 工具输出流或关闭详情卡顿 | 读工具实际结构化输出通道；设有界导航等待，确认旧调用结束 | 原对象状态已核验，未知外发不重放 |
| F15 折叠或视口变化漏读 | 原视口展开并留局部图，与全文/页底合并 | 补图缺失不算完整 |
| F16 恢复后页面引用失效 | 枚举原空间当前标签，重新核对对象和支持的 API 参数 | 不为旧标签失效新建空间 |
| F17 附件文本定位歧义 | 限定当前会话真实预览入口，核对附件身份；PDF文本层疑点回看原页 | 不拼猜联系方式；身份冲突停 |
| F18 Canvas跨域导出失败 | 停重复导出，回退普通可见截图与重叠全文覆盖 | 同人、页底和折叠均核验才继续 |
| F19 数量目标提前收尾 | 按原目标与已核验唯一发送重算剩余量；同run续接可执行工作 | 未达标不能报完成；已封存质量差异不自动补量 |
| F29 筛选未生效或旧列表 | 逐项设置并重开回读；切岗/页后等当前列表就绪 | 卡片存在不证明新条件已生效 |
| F30 intent落盘失败但外部动作发生 | 先查同人实际结果，修复本地门禁；把历史缺口保留 | 回读可恢复结果，不能伪称前置intent合规 |
| F32 证据目录编号碰撞 | 新目录先查不存在；旧目录须核同run同人同事务，恢复产物用独立attempt | 新事务隔离不等于被覆盖历史已恢复 |
| F33 检查器与封存质量例外冲突 | 分别展示开放目标剩余、已封存质量缺口及等待收件 | 不改目标、补发或伪报满额迎合检查器 |

恢复新类型时按症状、脱敏错误、已验证事实、原因confirmed/unknown、方案proposed/verified/failed、成功条件、停止边界写入。保留单实例失败与恢复历史；其他人一次恢复成功不能自动关闭本人的 blocked_read。涉及不同浏览器布局或文件类型的方案需重新验证。外部消息桥接相关故障不在本包处理范围。
