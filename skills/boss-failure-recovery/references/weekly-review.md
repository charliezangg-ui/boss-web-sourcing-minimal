# 失败记录与人工周期复盘

本包不建立 cron 或 IM 投递。用户要求复盘时，在明确时区与起止时间内读取私有 `failure-events.jsonl`、run 的 blocked/unknown/error 与恢复证据。每次错误实例保留，按故障链归并；重复下游错误关联同一 event_id。发现漏记可补录真实事件并标 backfilled，时间或原因缺证写 unknown，不猜。

报告列每类发生次数、受影响对象、恢复成功/仍阻塞/未知、漏记、已实测的文档修订和待验证方案。只有当前证据支持的恢复才改索引为 verified；推测单列 proposed。检查跨模块不变量：切页/放宽/暂停后是否保留原目标与同人计数；一级卡片及阶段耗时覆盖；已读后的已登记事务是否恢复；安全验证是否保持原空间。无覆盖写未测试，不写通过。复盘不操作 BOSS、不触发故障、不改变用户招聘标准或授权。
