# 寻访候选人

开始前绑定准确在招岗位、读取JD和本岗判定卡，按[筛选模块](../boss-candidate-filter/SKILL.md)核验条件。将核心责任转为产品/团队/项目与可迁移背景的搜索假设；关键词用于召回，不成为资格证明。按[先窄后宽](../boss-candidate-filter/references/search-strategy.md)在推荐与最新间切换，搜索/精选付费开聊另守预算边界。

每页实际读取可见一级卡片、建立匿名同人键并去重；已加载但未检查的不计。按[两级分流](references/list-triage.md)先冻结 `open_first/uncertain/skip_visible_mismatch` 与原始证据，再只给需要详情的人调用[完整读取](../boss-candidate-read/SKILL.md)及[逐关评审](../boss-candidate-screen/SKILL.md)。公司、学校、期望薪酬和关键词只影响优先级；明确硬冲突可跳过，未知不能伪作不符。一级不直接打招呼或作面试结论。

每次切页、刷新、修改条件前写[策略事件](references/strategy-ledger.md)：完整 requested/effective 条件、变化原因、窗口与通过率判据、剩余目标。逐人写卡片、详情、判断、动作及阶段耗时；下一人前检查本人的必填记录已可读。低产出按策略换入口/关键词/院校等用户可放宽项，不以成功率下降结束数量目标。重复、高跳过和空池分别记录证据。人工标注可按[本地反馈闭环](references/local-review-loop.md)用于后续校准；原始Agent结论不得被覆盖。
